A workspace project keeps the article, book and supplement files it consulted (review supplements scanned for accessions, articles read for provenance) out of git, and its records cite each by source address plus content digest, so an article, its supplement and a corrected version stay distinct; any location index is a lookup, not the citation. Proto-science kept papers/pdfs/ with references.bib; the current stack has no equivalent, and multiple-myeloma holds an interim gitignored data/references/ listed on mm-0a147a.
