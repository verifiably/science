conftest.certified_work defaults to REPO_ROOT/.framework-test. A worktree under .worktrees/ resolves onto the WORK_ROOT volume, whose ext4 mount options fail atoms' durability allowlist (CapabilityUnavailable: volume configuration is not on the supplied durability allowlist ... profile='flush-honoring-disk.v1'), so 36 tests fail and 13 error before any change. Setting SCIENCE_TEST_ROOT to a directory under the main checkout's .framework-test/ restores the main baseline. Candidates: the justfile exports a default that resolves through the main checkout when the repo root is a worktree; or AGENTS.md names the variable beside the worktree rule. Observed 2026-09-23 on the projects-spec worktree.
