pyproject.toml's dev group requires pytest-xdist>=3.6, but python/uv.lock's [package.metadata.requires-dev] omits it, so every uv run in a checkout or worktree rewrites the lock (also bumping revision 3 to 5 under uv 0.13.5) and leaves an uncommitted change. Run uv lock under python/, check the diff is only that, commit as chore(deps).
