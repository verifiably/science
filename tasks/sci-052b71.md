python/pyproject.toml declares verifiably-science 0.1.0. The name is free on PyPI, nothing is published, and there is no release workflow. There is no ts package, so npm does not arise.

The judgement is what kind of artifact this is. science is the daily surface — harness-neutral commands and skills, generated harness adapters, the CLI and MCP over beliefs — which reads as an application rather than a library other code imports. That argues for PyPI with a console script so it can be installed or run with uvx, rather than a library release, and it argues for shipping later than the layers beneath it.

It also cannot ship before beliefs, which it depends on, and beliefs cannot ship before atoms. Gated on ops-f1a933.
