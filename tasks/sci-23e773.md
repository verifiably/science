Dispatcher._kernel_refusal renders a KernelRefusalValue as Refusal('kernel-refused', str(value.reason), {kind, reason}); a RunRefused also carries detail (e.g. "a1_coverage.pth imports 'sys', which is not a closure member"), which never reaches the caller, so a refusal reads only 'closure-unsupported' and diagnosing it needed a debug print in the handler (found 2026-09-23, Task 7). Carry detail in data (and the message) when the value has one; replay equality is unaffected since the envelope is what the ledger stores.
