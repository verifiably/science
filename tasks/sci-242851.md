An admitted store can contain bytes altered after admission. Science run.prepare resolves the declared dataset address to a held path; beliefs boundary._stage_inputs copies that path and records the staged digest but does not compare it to the declared resource digest. A run or replay can therefore consume bytes different from the dataset it names. This predates readable stores and was explicitly excluded from sci-300dab; it is not a failure to implement that task.

Wanted: refuse a declared-content mismatch before workflow execution, comparing the exact staged bytes that execution will consume against the declaration's expected content identity. Cover both run and verify, ordinary writable stores and inherited read stores. Keep deterministic carrier selection: a mismatch must not silently select another holding. Use the project's existing refusal/reporting route and preserve invocation closure; do not publish successful scientific evidence for mismatched input.

Start with science python/src/science/commands/run.py::prepare and commands/verify.py, and beliefs python/src/beliefs/boundary.py::_stage_inputs and its analysis/production/planning callers. Read [ref:stores] and [ref:review]. The staging boundary is kernel-owned; settle how trusted expected digests reach it, then file/link the beliefs implementation slice during design rather than inserting a source-file precheck vulnerable to change before staging. Identify which existing declarations carry comparable digests and explicitly settle behavior for unsupported forms. Avoid silently broadening this into multi-resource staging or dataset-production publication, already investigated by sci-dfec5b.

Acceptance: a synthetic admitted store whose payload is changed after a valid holding is refused before execution through both science run and verify; an unchanged holding succeeds; inherited and write-store cases share the enforcement; a source change during copying is checked against the resulting staged bytes; planning or replay restaging cannot bypass the same check; refusal leaves coherent terminal invocation evidence. Exercise the common kernel boundary and science consumer paths with focused tests. No live-world repair, automatic migration, alternative-copy retry, or payload rewriting.

Priority rationale: silent wrong-input scientific runs affect evidence validity. This follow-up changes the execution contract and therefore needs design and plan review; it does not reopen or block the already completed readable-stores feature. Existing rollout and unmatched-intent work remain mm-62e2da and sci-409235.
