Run `dataset` when the user has a data file or directory of files on this
machine that an analysis will observe, or the vocabulary list a contract
binds. Give the file or directory path and a title; add `resources` to select
relative POSIX file paths within a directory (absent, all regular files under
the directory are held), `locator` for an accession the record should cite,
and `facets` for domain facets the contract declares. The output is the minted
record only; if it refuses, report the refusal and change nothing.
