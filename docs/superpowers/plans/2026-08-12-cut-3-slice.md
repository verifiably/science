# Conformance cut 3 slice — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bank conformance cut 3 (`docs/designs/2026-08-11-conformance-cut-3.md`)
and build its slice — the run boundary: spec freezing and closure construction,
the execution boundary through the **minimal Snakemake adapter**, dataset
production, replay and verification-as-value, and the completion and report
layer — so that every arm the cut selects (§4.1/§4.2 as amended through §7.3)
is a passing, sabotage-able check.

**Architecture:** Five crossings, each its own module cluster: the analysis-spec
freeze (`spec.py`), recipe/closure construction (`recipe.py`), the execution
boundary over a real Snakemake subprocess in boundary-owned scratch roots
(`adapter.py`, `boundary.py`), dataset production (`production.py`), replay and
verification (`replay.py`, `verify.py`, `assess.py`), and the report layer
(`report.py`). Runs, intents, act-reports and verifications are **values** —
no store, no world index, no persistence of any kind. Belief is consumed, never
rebuilt: cut 2's `record.py`/`closure.py`/`admission.py`/`belief.py` machinery
is imported by its real names and composed with, not duplicated.

**Tech Stack:** Python ≥3.11, `uv`, `pytest`, `ruff` (line length 120),
`pyright` (src only). **One new dependency: `snakemake`**, added in Task 5.

## Global Constraints

These come from the frozen cut (`2026-08-11-conformance-cut-3.md`), the designs
it selects from (computation §3–§7.3c, act-report §2–§5), and the user's
standing rules. Every task's requirements implicitly include this section.

- **The frozen selection is the acceptance criteria.** The slice implements
  exactly the in-cells of cut 3 §4.1/§4.2. Results are recorded separately
  (Task 13), **never by editing the selection**. If an arm turns out
  unimplementable as frozen, STOP and report — the selection is amended by
  preserving the original verbatim with a stated reason, never by silently
  narrowing a test. **An arm from a deferred cell is scope creep and a
  review-blocker** — no test may claim an arm §4.2's deferred columns name.
- **No persistence of any kind.** Runs, intents, act-reports, and verifications
  are values; no store, no world index, no rules store, no resolver, no
  correction lifecycle, no acquisition, no probe, no confinement. Corpora exist
  as **supplied node→corpus attributions** with per-corpus pins — cut 2's
  fixture form (`consulted.CorpusPins`, plain mappings).
- **Execution is real:** subprocesses in **boundary-owned scratch roots** —
  tmp directories under the test session (`tmp_path` / `tmp_path_factory`).
  A scratch root is **staging by location, NOT confinement**. The suite's
  fixtures perform no network access and no IO outside the scratch roots and
  fixture inputs — a property of the fixtures, which the **boundary does not
  enforce**.
- **The minimal Snakemake adapter:** fixtures supply a **held single-rule
  workflow definition** (a Snakefile fixture). The boundary captures its
  identity as a **recipe** member (`workflow_definition_identity`), renders
  **only** engine configuration, environment, and argv (computation §4.2b), and
  invokes the definition through Snakemake. **The boundary never generates or
  renders a workflow definition.** Snakemake is added to
  `python/pyproject.toml` dependencies with `uv add snakemake==8.11.4`
  followed by `uv lock` (Task 5) — **pinned exactly**: the adapter's trace
  channel is written against the 8.11.4 `--log-handler-script` contract — and
  every verification command remains `uv run --frozen ...` from `python/`.
- **Boundary input safety — all three rules, enforced and tested:** execution
  is by **direct argv with `shell=False`**; engine **targets are separated from
  options**, with option-like targets (leading `-`) rejected — `shell=False`
  prevents shell injection, not option injection; and the **entrypoint must
  resolve to a regular file inside the captured bundle** before anything runs.
- **`clean-environment` is unreachable in every arm.** No scope walk may derive
  it — the boundary's receipts attest no confinement capability, and the
  derivation requires one — and no cut-3 execution reaches admitted belief.
  T4's inertness arms run against **cut 2's already-admitted value fixtures**.
- **Style is cut 1/2's:** frozen `@sealed @final @dataclass` value types; every
  refusal a distinct class under `ScienceError` (see `errors.py`); refusals
  that are *outcomes* (a run request the boundary rejects, a completion
  reading) are **returned values**, never exceptions; module docstrings name
  the banked rows the module carries and cite design sections;
  availability-like inputs are **explicit parameters with no defaults**
  (M11 discipline).
- **Identity:** all digests via `science.identity.v1` (`v1.digest(domain, obj)`).
  New domains: `science.spec.v1`, `science.workflow-definition.v1`,
  `science.environment.v1`, `science.recipe.v1`, `science.run.v1`,
  `science.act-report.v1`, `science.comparison-report.v1`,

- **Test names carry their row.** Every arm-bearing test is a flat function

  - `ExclusionCertification(rationale: str, attribution: str)` — both non-empty (`MalformedSpec`).   - `FrozenSpec` — the draft's fields plus `rule_bindings: tuple[tuple[str, str], ...]`, `supersedes: str | None`, and `identity: str`
  - `freeze(draft: SpecDraft, *, held_rules: Mapping[str, RuleImplementation], supersedes: str | None = None) -> FrozenSpec`
  - `revise(original: FrozenSpec, *, edits: Mapping[str, object], held_rules: Mapping[str, RuleImplementation], recorded_failures: frozenset[str]) -> FrozenSpec` — the only edit path; always mints with `supersedes=original.identity`
  - `SuccessorAdmitted(candidate: str)` / `SuccessorRefused(candidate: str, reason: str)`

def derive_seed(stream_root: int, semantic_job_key: str, stream_key: str) -> int:
    """`seed = f(stream_root, semantic_job_key, stream_key)` (computation §6.2),
    the v1 derivation rule: deterministic, keyed by job AND stream."""
    material = f"{stream_root}\n{semantic_job_key}\n{stream_key}".encode("utf-8")
    return int.from_bytes(sha256(material).digest()[:8], "big")


@sealed
@final
@dataclass(frozen=True)
class SeedPlan:
    derivation_rule: str
    streams: tuple[str, ...]
    """Logical stream identities — analytical roles (`model-initialization`),
    never library or workflow-rule names. No field for families exists here:
    the per-family declaration is the workflow-definition snapshot's (§3.1a),
    which is what keeps `independent-implementation` reachable (R20 neg. (d))."""
    roots: Mapping[str, int]
    stream_roots: Mapping[str, str]

    def __post_init__(self) -> None:
        unmapped = set(self.streams) - set(self.stream_roots)
        if unmapped:
            raise MalformedSpec(f"streams with no root: {sorted(unmapped)} — the mapping must be total")
        undeclared = set(self.stream_roots.values()) - set(self.roots)
        if undeclared:
            raise MalformedSpec(f"mapped roots nobody declared: {sorted(undeclared)}")
        if set(self.stream_roots) - set(self.streams):
            raise MalformedSpec("a mapping entry for an undeclared stream")
        object.__setattr__(self, "roots", MappingProxyType(dict(self.roots)))
        object.__setattr__(self, "stream_roots", MappingProxyType(dict(self.stream_roots)))

    def projection(self) -> dict[str, object]:
        return {
            "derivation_rule": self.derivation_rule,
            "streams": sorted(self.streams),
            "roots": {k: v for k, v in self.roots.items()},
            "stream_roots": {k: v for k, v in self.stream_roots.items()},
        }

    Nested by construction — a flat, job-keyed record has one slot for two
    streams and cannot represent a two-stream plan (R20 negative (b))."""

                    "one slot cannot hold two streams (computation §6.2)"

        object.__setattr__(
            self, "seeds", MappingProxyType({k: MappingProxyType(dict(v)) for k, v in self.seeds.items()})
        )

        return {job: dict(per_stream) for job, per_stream in self.seeds.items()}

class ExclusionCertification:
    rationale: str
    attribution: str

    def __post_init__(self) -> None:
        if not self.rationale or not self.attribution:

@sealed
@final
@dataclass(frozen=True)
class SpecInput:
    role: str
    dataset: str
    exclusion: ExclusionCertification | None = None

    def __post_init__(self) -> None:
        if self.role not in SPEC_INPUT_ROLES:
            raise MalformedSpec(f"input role {self.role!r} is outside the closed set {SPEC_INPUT_ROLES}")
        if self.exclusion is not None and self.role != "reads":
            raise MalformedSpec("an exclusion certification is inline on a `reads` entry only (§5.2)")


@sealed
@final
@dataclass(frozen=True)
class RuleFixture:
    arguments: tuple[object, ...]
    expected: object


@sealed
@final
@dataclass(frozen=True)
class RuleImplementation:
    identity: str
    evaluate: Callable[..., object]
    fixtures: tuple[RuleFixture, ...]

    def __post_init__(self) -> None:
        if not self.identity:
            raise MalformedSpec("an implementation carries its content identity")


def implementation_conforms(impl: RuleImplementation) -> bool:
    """An evaluator that raises does not conform; comparison is exact (==)."""
    for fixture in impl.fixtures:
        try:
            if impl.evaluate(*fixture.arguments) != fixture.expected:
                return False
        except Exception:
            return False
    return True


def bind_rules(named: tuple[str, ...], held: Mapping[str, RuleImplementation]) -> tuple[tuple[str, str], ...]:
    bound: dict[str, str] = {}
    for rule in named:
        if rule not in held:
            raise RuleUnbound(f"{rule!r} names no held implementation — the registry route is the rules store's")
        if not implementation_conforms(held[rule]):
            raise RuleUnbound(f"{rule!r}: the held implementation fails its fixtures and is not that rule (§3.1b)")
        bound[rule] = held[rule].identity
    return tuple(sorted(bound.items()))

@final

@sealed
@final
@dataclass(frozen=True)
class SuccessorAdmitted:
    candidate: str


@sealed
@final
@dataclass(frozen=True)
class SuccessorRefused:
    candidate: str
    reason: str


def admit_successor(candidate: FrozenSpec, superseded: FrozenSpec,
                    recorded_failures: frozenset[str]) -> SuccessorAdmitted | SuccessorRefused:
    """G4 over the slice's value state — the recorded-failure set the boundary
    holds. A failure absent from the set never happened: undetectable."""
    if superseded.identity in recorded_failures and candidate.supersedes != superseded.identity:
        return SuccessorRefused(candidate.identity, "an unreferenced successor to a recorded failed replay")
    return SuccessorAdmitted(candidate.identity)


def _facet_projection(draft: SpecDraft, rule_bindings, supersedes) -> dict[str, object]:
    facet: dict[str, object] = {
        "target": draft.target,
        "estimand": draft.estimand,
        "method": draft.method,
        "assumptions": draft.assumptions,
        "falsification": draft.falsification,
        "input_roles": [
            {"role": entry.role, "dataset": entry.dataset}
            | ({"exclusion": {"rationale": entry.exclusion.rationale,
                              "attribution": entry.exclusion.attribution}}
               if entry.exclusion is not None else {})
            for entry in draft.input_roles
        ],
        "applicability": draft.applicability,
        "interpretation_rule": draft.interpretation_rule,
        "equivalence_rule": draft.equivalence_rule,
        "parameters": dict(draft.parameters),
        "nondeterminism": draft.nondeterminism.projection(),
        "rule_bindings": [list(pair) for pair in rule_bindings],
    }
    if supersedes is not None:
        facet["supersedes"] = supersedes  # absent, never null (identity v1)
    return facet


def freeze(draft: SpecDraft, *, held_rules: Mapping[str, RuleImplementation],
           supersedes: str | None = None) -> FrozenSpec:
    if not draft.target:
        raise MalformedSpec("an assessment spec targets a proposition; an empty target is not a spec (R7)")
    if isinstance(draft.nondeterminism, StochasticUnseeded) and draft.equivalence_rule in BITWISE_EQUIVALENCE_RULES:
        raise UnfreezableSpec(
            "stochastic-unseeded cannot support a bitwise equivalence rule — the §1.2 contradiction, "
            "caught at freeze because both halves are now in one frozen record (computation §3.1a)"
        )
    rule_bindings = bind_rules((draft.interpretation_rule, draft.equivalence_rule), held_rules)
    identity = v1.digest(SPEC_DOMAIN, _facet_projection(draft, rule_bindings, supersedes))
    members = {f.name: getattr(draft, f.name) for f in fields(SpecDraft)}
    return FrozenSpec(**members, rule_bindings=rule_bindings, supersedes=supersedes, identity=identity)


def revise(original: FrozenSpec, *, edits: Mapping[str, object],
           held_rules: Mapping[str, RuleImplementation],
           recorded_failures: frozenset[str]) -> FrozenSpec:
    """The only edit path. Always mints with `supersedes=original.identity`,
    so the successor to a recorded failed replay carries its reference by
    construction; `admit_successor` is the value-state check the boundary
    applies to specs it did not mint (G4)."""
    draft = SpecDraft(**{f.name: edits.get(f.name, getattr(original, f.name))
                         for f in fields(SpecDraft)})
    return freeze(draft, held_rules=held_rules, supersedes=original.identity)

**Interfaces:**
- Consumes: `recipe.TraceJob`, `recipe.EnvironmentManifest`, `spec.RealizedSeeds`, errors (`UnsafeInvocation`, `MalformedClosure` — the fail-closed capture refusals).
- Produces:
  - `WORKFLOW_DEFINITION_DOMAIN = "science.workflow-definition.v1"`
  - `WorkflowDefinition(snakefile: bytes, family_streams: Mapping[str, tuple[str, ...]])` with `.identity() -> str` — the **held** definition, fixture-supplied and never boundary-rendered; `family_streams` is §6.2's per-family stream declaration, carried by the snapshot and never by the spec
  - `create_scratch_root(base: Path) -> Path` — a fresh boundary-owned directory (`mkdtemp` under `base`); **staging by location, not confinement**
  - `capture_bundle(code_roots: tuple[Path, ...], bundle_dir: Path) -> str` — copies every file, untracked and uncommitted included (`.git` directories excluded — the repository is not the code), and returns `"sha256:" + hex` over sorted `(posix relative path, content sha256)` rows
  - `capture_environment() -> EnvironmentManifest` — records **the environment that will actually execute, as held bytes** (§4.5: held content, never a recipe for content — a `name==version` or path/version digest is lockfile-shaped metadata and exactly what R1 negative (b) refuses): one `("python", digest)` row over the **interpreter binary's actual bytes** (`Path(sys.executable).resolve().read_bytes()`), plus one `("dist:<canonical name>", distribution_digest(dist))` row per importable distribution. Every row name is a **location-independent logical name** — no absolute path appears anywhere in the manifest, so identical bytes reached via a different mount yield an equal manifest while a single mutated artifact byte moves it. The engine subprocess is `sys.executable -m snakemake`, so what is captured is what runs — no caller-supplied environment exists anywhere
  - `distribution_digest(dist: importlib.metadata.Distribution) -> str` — folds the distribution's installed file bytes: sorted `(RECORD-relative path, sha256 of bytes)` rows over every RECORD-listed entry that resolves to an existing regular file (`dist.files` / `dist.locate_file`), digested. RECORD paths are already install-root-relative, which is what keeps the digest location-independent. Public, because the byte-mutation and relocation tests drive it over a purpose-built fixture distribution (`importlib.metadata.Distribution.at`)
  - `require_executing_environment(manifest: EnvironmentManifest) -> None` — recomputes the capture and raises `MalformedClosure` when the supplied manifest does not match the interpreter about to be exec'd; the boundary calls this immediately before `run_engine`, so a recipe claiming environment A can never run in environment B through this boundary (§4.5)
  - `validate_entrypoint(bundle_dir: Path, entrypoint: str) -> Path` — must resolve (symlinks followed) to a **regular file inside the captured bundle**; anything else → `UnsafeInvocation`
  - `build_argv(*, snakefile: Path, scratch: Path, targets: tuple[str, ...], config: Mapping[str, str], log_handler: Path, cores: int) -> tuple[str, ...]` — direct argv for `sys.executable -m snakemake`; any option-like target (leading `-`) → `UnsafeInvocation`; any config **key** that is not an identifier (`^[A-Za-z_][A-Za-z0-9_]*$`) → `UnsafeInvocation`, so a key can never become an option-shaped argument; targets follow a literal `--` terminator (argparse's option/positional delimiter, which the pinned 8.11.4 CLI honors), so even a target that slipped the check could not parse as an option; `cores` is scheduling-only and reaches no recipe member
  - `run_engine(argv: tuple[str, ...], cwd: Path, env: Mapping[str, str]) -> tuple[int, str]` — `subprocess.run(list(argv), shell=False, capture_output=True, text=True, cwd=cwd, env=dict(env))`; returns `(returncode, stdout + stderr)` — the streams are diagnostics only and are **never parsed for trace content**
  - `LOG_HANDLER_SCRIPT: str` — the boundary-rendered `--log-handler-script` body (engine configuration, which is the boundary's to render): Snakemake 8.11.4 calls the script's `log_handler(msg)` with dictionary messages, and the script appends each `job_info` message as one JSON line to the file named by the `SCIENCE_TRACE_FILE` environment variable — a boundary-owned file outside the scratch root. The handler channel is the **trusted-by-convention source**: an unconfined subprocess inherits the environment and could write to it — this cut's fixtures perform no IO outside the scratch roots and fixture inputs, the **boundary does not enforce that**, and adversarial tampering with the channel is deferred with the confinement-capable boundary policy and the tamper log (cut 3 §3)
  - `read_trace(events_file: Path) -> tuple[TraceJob, ...]` — parses the handler channel's JSON lines into `TraceJob` rows. **Fail-closed:** a missing or empty events file after a successful run, an unparseable line, or a record missing **any** of `jobid`, its rule name, `input`, `output`, or `wildcards` raises `MalformedClosure` — nothing is silently defaulted, there is **no ordinal fallback**, and no run is minted over a trace the engine did not report
  - `read_realized_seeds(scratch: Path) -> RealizedSeeds` — the minimal adapter's **cooperative reporting channel**, not an independent boundary observation: each executed job reports the seeds it claims to have drawn as JSON under `<scratch>/.seeds/<job>.json` (`{job_key: {stream_key: seed}}`). The occurrence records what jobs claim; R16's conformance evaluates the claims against the plan. **Fail-closed:** malformed JSON, a non-nested record, or **any second report for one `(job, stream)` — agreeing or not** — raises `MalformedClosure`: a duplicate claim is a channel the boundary cannot read, not a coincidence to merge. No run is minted over an unreadable report; an absent directory is the empty claim `RealizedSeeds(seeds={})`

_CONFIG_KEY = re.compile(r"^[A-Za-z_][A-Za-z0-9_]*$")

LOG_HANDLER_SCRIPT = '''\
import json
import os

_EVENTS = os.environ["SCIENCE_TRACE_FILE"]


def log_handler(msg):
    if msg.get("level") == "job_info":
        with open(_EVENTS, "a", encoding="utf-8") as events:
            events.write(json.dumps(msg, default=str) + "\\n")
'''


def build_argv(*, snakefile: Path, scratch: Path, targets: tuple[str, ...],
               config: Mapping[str, str], log_handler: Path, cores: int) -> tuple[str, ...]:
    for target in targets:
        if target.startswith("-"):
            raise UnsafeInvocation(
                f"target {target!r} is option-like; shell=False prevents shell injection, "
                "not option injection — targets are separated from options (cut 3 §3)")
    for key in config:
        if not _CONFIG_KEY.fullmatch(key):
            raise UnsafeInvocation(f"config key {key!r} is not an identifier and could parse as an option")
    argv = [sys.executable, "-m", "snakemake", "--snakefile", str(snakefile),
            "--cores", str(cores), "--directory", str(scratch), "--nolock",
            "--log-handler-script", str(log_handler)]
    if config:
        argv.append("--config")
        argv.extend(f"{key}={value}" for key, value in sorted(config.items()))
    argv.append("--")  # argparse's terminator: everything after is positional, always
    argv.extend(targets)
    return tuple(argv)

```python
def _file_digest(path: Path) -> str:
    return "sha256:" + sha256(path.read_bytes()).hexdigest()


def distribution_digest(dist: importlib.metadata.Distribution) -> str:
    """Held bytes under location-independent names: sorted (RECORD-relative
    path, content digest) rows, folded. A mutated byte moves this; a relocated
    identical tree does not (§4.5)."""
    rows = []
    for entry in dist.files or ():
        located = Path(str(dist.locate_file(entry)))
        if located.is_file():
            rows.append((entry.as_posix(), _file_digest(located)))
    folded = "".join(f"{name}\n{digest}\n" for name, digest in sorted(rows)).encode("utf-8")
    return "sha256:" + sha256(folded).hexdigest()


def capture_environment() -> EnvironmentManifest:
    """The executing environment as held content: the interpreter binary's
    bytes and each importable distribution's installed file bytes, all under
    logical names — never a path, never a version string (§4.5). Recomputed
    on every call; the module-scoped test fixtures amortize the hashing cost,
    and a cross-call cache would be a silent staleness assumption."""
    rows = {("python", _file_digest(Path(sys.executable).resolve()))}
    for dist in importlib.metadata.distributions():
        name = dist.metadata["Name"].lower().replace("_", "-")
        rows.add((f"dist:{name}", distribution_digest(dist)))
    return EnvironmentManifest(artifacts=tuple(sorted(rows)))


def require_executing_environment(manifest: EnvironmentManifest) -> None:
    if manifest != capture_environment():
        raise MalformedClosure(
            "the recorded environment is not the executing environment — a recipe claiming "
            "environment A cannot run in environment B through this boundary (§4.5)")
```

### Task 6: The execution boundary — begin, execute, capture (`boundary.py`)

The five-step crossing: pre-intent refusals, the intent opened before the act,
projection-enforced recipes, real execution through the adapter, capture, and
boundary-only manifest construction and run minting.

**Files:**
- Create: `python/src/science/boundary.py`
- Test: `python/tests/test_boundary.py`
- Modify: `python/tests/fixtures_cut3.py` (the staging + execution helpers)

**Interfaces:**
- Consumes: everything from Tasks 2–5.
- Produces:
  - `RunMinted(run: RunClosure, intent: AssessmentRunIntent | OperationIntent, registration: Registration)`
  - `RunRefused(reason: str, report: ActReport | None, intent: AssessmentRunIntent | OperationIntent | None, registration: Registration | None)` — a refusal is an **outcome**, never an exception; a pre-intent refusal has `intent=None`, `registration=None`, and an **unfulfilling** report whose token was minted at the refusal itself
  - `execute_assessment_run(*, spec: object, definition: WorkflowDefinition, code_roots: tuple[Path, ...], held_inputs: Mapping[str, Path], entrypoint: str, targets: tuple[str, ...], declared_outputs: tuple[str, ...], actor: str, observer: str, started_at: str, host_realization: str, scratch_base: Path, cores: int = 1) -> RunMinted | RunRefused` — **no `inputs`, `parameters`, `nondeterminism`, `seed`, `scope`, `environment`, or manifest parameter exists** (R17, R21, R4): the environment member is `capture_environment()`, the executing interpreter's own manifest, and nothing a caller supplies
  - `execute_production_run(*, inputs: tuple[RecipeInput, ...], parameters: Mapping[str, object], nondeterminism, definition, code_roots, held_inputs, entrypoint, targets, declared_outputs, actor, observer, started_at, host_realization, scratch_base, cores: int = 1) -> RunMinted | RunRefused` — the dataset-production recipe **is** authored directly, seed plan included (R17 negative (b)); opens an `OperationIntent(kind="run-attempt")` (T2)
  - **The definition tie:** before execution, the captured entrypoint's bytes must equal the held `definition.snakefile` bytes — a mismatch is `RunRefused("definition-mismatch", …)`, so declared-A/executed-B is unspellable through the boundary. The snapshot identity is always taken from the **held definition**; the byte comparison is what ties that identity to what actually runs
  - `build_manifest(declared_outputs: tuple[str, ...], scratch: Path) -> ResultManifest` — content-addresses every declared output on disk; a missing one → `MalformedClosure`
  - `mint_run(recipe: Recipe, manifest: ResultManifest, occurrence: Occurrence, scratch: Path) -> RunClosure` — re-verifies each manifest digest against the bytes on disk before minting; a disagreement → `MalformedClosure` (R21's digest-mismatch clause, genuinely checkable at the mint). A trace or seed report the channels could not deliver (`MalformedClosure` from `read_trace` / `read_realized_seeds`) likewise mints no run — capture is fail-closed

Execution flow (assessment shape), the order load-bearing:

1. **Pre-intent checks** — refused **before any intent exists**, and a
   surviving boundary publishes an unfulfilling `run-attempt` act-report
   (subject: the supplied spec ref as supplied, `"absent"` where none):
   `spec` not a `FrozenSpec` (a draft, a bare identity string, `None`) →
   `RunRefused("no-frozen-spec", report, None, None)` (G2a, R12, T2); any
   spec input whose address is URL- or accession-shaped (`"://"` in it, or an
   `accession:` prefix) → `RunRefused("acquisition-not-a-run", …)` — no
   fallback synthesizes a dataset entity (R10); a declared input absent from
   `held_inputs` → `RunRefused("input-not-held", …)`.
2. **The intent**: `AssessmentRunIntent(spec.identity, fresh token, actor)`.
3. **Capture**: fresh scratch root under `scratch_base`; `capture_bundle`;
   `capture_environment()` — the executing interpreter's own manifest, no
   caller-supplied environment existing anywhere; `validate_entrypoint`; the
   **definition tie** — the captured entrypoint's bytes must equal
   `definition.snakefile` or the request refuses post-intent
   (`"definition-mismatch"`); held inputs content-addressed from their
   fixture bytes and staged into `<scratch>/inputs/`; the recipe
   **projected** via `project_recipe`; family-stream union checked against the
   plan (a mismatch refuses — machinery only: every family/coverage arm is
   deferred to the full workflow surface, and no test names one).
4. **Rendering**: `--config` pairs from the projected `parameters` plus, for a
   `Seeded` plan, `seed_<stream>` entries derived by
   `derive_seed(plan.roots[plan.stream_roots[s]], family, s)` per declared
   family stream — keys rendered as identifiers (`seed_` prefix, `-` → `_`)
   and validated again by `build_argv` — plus the log-handler script written
   into a **boundary-owned trace directory beside (never inside) the scratch
   root**. The rendering appears in the receipt. The boundary renders
   configuration, environment and argv — **never the definition**.
5. **Execute**: `require_executing_environment(recipe.environment)`
   immediately before `run_engine` (`shell=False`, env carrying
   `SCIENCE_TRACE_FILE` → the boundary-owned events file). A nonzero exit or
   a manifest failure after a successful intent → `RunRefused` carrying the
   intent, a `run-attempt` act-report with the intent's token, and a
   registration pointing at the report — the boundary's cooperative no-run
   closure. (Its qualification force is T3-tested; T2's
   one-intent-one-terminal arm stays deferred with persistence.)
6. **Capture out**: trace read from the handler channel (`read_trace` —
   fail-closed; no run over a trace the engine did not report), realized
   seeds read from the **cooperative** `.seeds` channel (the occurrence's
   record of what jobs claim — conformance evaluates the claims; also
   fail-closed on malformed or duplicate reports, agreement included), receipt built (scratch
   mapping, argv, rendered config, `capabilities=()` — nothing here can
   attest confinement).
7. **Mint**: `build_manifest` → `mint_run` → `RunMinted(run, intent,
   Registration(intent.event_token, run.address()))`. A seed-plan violation
   does **not** stop the mint — a complete closure disobeyed is a
   non-conforming run (R16, R21 negative (e)), derived later, stored nowhere.
